# Changelog

All notable changes to the StillHere project will be documented in this file.

## [0.1.0] - 2026-08-05
### Added
- Initial implementation of `StillHereCore` and `ScammerRegistry` Intelligent Contracts on GenLayer `studionet`.
- Non-deterministic AI Jury execution (`gl.vm.run_nondet`) with semantic validator checks.
- Privacy & safety safeguards E1–E8 (chat log hashing, PII protection, verdict normalization E4).
- Dispute mechanism (Round 2 appellate re-adjudication).
- `gltest` test suite with mock LLM/web scenarios.
- Vite + React + TypeScript + Tailwind CSS frontend dApp with `genlayer-js` and MetaMask integration.
- Complete documentation (`README.md`, `ETHICS.md`, `PROMPT_DESIGN.md`, `SECURITY.md`, `deploy.md`).
