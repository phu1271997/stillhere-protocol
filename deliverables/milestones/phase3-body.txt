Phase 3 upgrades the smart contracts and adds analytics so families and moderators can see how the protocol is used, and so wallets that surface real scams build a public reputation. Fresh deploy of the two main contracts.

Before: nobody knew if a wallet had a track record. No dashboard for cases or verdicts. If the Jury could not decide, the fee was stuck. Nobody could follow a profile. Jury read only the profile page.

After:
1. Reputation tiers — each wallet earns Guardian / Trusted / Newcomer / Suspect / Unranked from history. Advisory, never fed into a verdict.
2. Analytics dashboard — a Stats page shows total cases, verdicts by category, and pause state.
3. Failed-case refund — if the Jury cannot decide, the payer gets money back.
4. Emergency pause — admin can freeze new cases while withdrawals stay open.
5. Watch a profile — subscribe or unsubscribe from a profile hash.
6. Smarter AI — Jury cross-references four public sources before calling a profile a scammer.
