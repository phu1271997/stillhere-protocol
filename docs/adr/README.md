# Architecture Decision Records — StillHere

Small, dated snapshots of decisions that shape the protocol. Each ADR
answers three questions in the same order:

1. **Context** — what forced the decision?
2. **Decision** — what we chose, in one paragraph.
3. **Consequences** — what that choice buys us and what it costs.

We keep the rejected alternatives around explicitly. Future contributors
should be able to see *why* we did not do the obvious-looking thing.
